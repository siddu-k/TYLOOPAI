Project Defense & Architecture Overview Slide 1 of 10
Problem Definition

Beyond Monolithic Plain Text AI

Current AI assistants restrict users to static text feeds. Complex computer science, engineering circuits, and algorithms require spatial, visual, and embodied comprehension.

Text-Only Bottleneck

Abstract algorithms (e.g. Red-Black trees, neural backprop, CPU pipelining) cannot be taught efficiently through plain text walls.

Cognitive Friction

Passive vs Interactive

Users need dynamic 2D vector flowcharts, rotatable 3D spatial coordinate models, and real-time assessments, not passive reading.

Spatial Mechanics

Cloud Lock-in & Privacy

Commercial LLMs demand mandatory cloud network connections and expose sensitive engineering code to remote servers.

Data Sovereignty

Architectural Blueprint Slide 3 of 10
Core Engine

Dual Inference System (Cloud + Offline)

A unified API abstraction layer routing requests based on connectivity, hardware acceleration, and privacy preference.

Google Gemini Cloud (API)

High-throughput multimodal intelligence via Google GenAI SDK. Powered by gemini-3.5-flash-lite for sub-second responses and rich structured outputs.

• Full streaming token decoder via Web Streams API
• Automatic API key testing and fallback validation
• Generates complex Mermaid graphs and 3D Three.js scene code

Ollama Local AI (Zero Cloud)

Direct native HTTP streaming to localhost:11434. Download, pull, and run weights on user hardware with zero external dependencies.

• Live in-app model downloader with real-time percentage progress
• Supports Qwen 2.5 Coder, Llama 3.2, DeepSeek, and Mistral
• 100% offline data retention with zero tracking
